# 台灣金融業 AI 動態追蹤與 Excel 自動更新技能

當執行此技能時，請依序完成以下四個階段：

## 階段 1：每日最新情報搜尋
使用瀏覽器工具 (`/browser`) 針對台灣各大金控（富邦金、國泰金、中信金、玉山金、元大金、凱基金、台新新光金、永豐金、兆豐金、第一金、華南金、合庫金等）及其銀行、證券、人壽子公司，搜尋過去 24 小時內發布之 AI 相關新聞、法說會揭露或研究發表。

## 階段 2：依指定卡片格式產出每日摘要報告
請嚴格依照以下結構條列每家有新動態的機構（並同步儲存至 `daily_reports/YYYY-MM-DD.md`）：

### [機構名稱，例如：永豐金證券 / 凱基證券]
**AI 應用**
* **生成式AI**（若無則省略該子標題）
  * ① [具體應用名稱與量化成效，若原文未明示底層技術請於句尾加上 `[技術分類推估]`]
* **傳統AI / 機器學習**（若無則省略該子標題）
  * ① [具體應用名稱、演算法或模型成效，未明示技術者加上 `[技術分類推估]`]

**Agent 進度**
* ① **子公司**：[揭露具體 AI Agent 應用場景，若無則寫「無子公司層級Agent揭露」或「無具體揭露」]
* ② **集團層級 / 治理**：[例如：國泰金「Agent First」、凱基金控風管數位智庫、或成立人工智慧治理委員會等]

## 階段 3：分類映射與寫入 Excel
將確認屬於實際業務場景的新項目，依 `金融業AI場景應用.xlsx` 中「分類說明」工作表的 14 個類別（`RAG/KM`、`語音質檢/應用`、`生成式AI`、`比對`、`阻詐`、`M365 Copilot`、`AI Agent`、`OCR`、`智能客服`、`程式助手`、`RPA`、`模型訓練`、`App`、`其它`）進行單一分類，並執行 `python3 .agents/skills/tw-fin-ai-tracker/scripts/update_excel.py` 寫入 Excel。

## 階段 4：自動同步至 GitHub（選用）
更新完成後，執行 `git add 金融業AI場景應用.xlsx daily_reports/ && git commit -m "chore: update daily financial AI scenarios" && git push`，讓線上儀表板即時同步。
