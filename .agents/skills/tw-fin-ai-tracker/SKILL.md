# 台灣金融業 AI 動態追蹤與 Excel 自動更新技能

當執行此技能時，請依序完成以下四個階段：

## 階段 1：每日最新情報搜尋
使用瀏覽器工具 (`/browser`) 針對台灣各大金控（富邦金、國泰金、中信金、玉山金、元大金、凱基金、台新新光金、永豐金、兆豐金、第一金、華南金、合庫金、國票金、臺灣金等）及其銀行、證券、壽險子公司與周邊金融機構，搜尋過去 24 小時內發布之 AI 相關新聞、法說會揭露或研究發表。

## 階段 2：依指定卡片格式產出每日摘要報告
請嚴格依照以下結構條列每家有新動態的機構（並同步儲存至 `daily_reports/YYYY-MM-DD.md`，檔名日期採台灣台北時區 `Asia/Taipei` 當天日期）：

### [機構名稱，例如：永豐金證券 / 凱基證券]
**AI 應用**
* **生成式AI**（若無則省略該子標題）
  * ① [具體應用名稱與量化成效，若原文未明示底層技術請於句尾加上 `[技術分類推估]`]
* **傳統AI / 機器學習**（若無則省略該子標題）
  * ① [具體應用名稱、演算法或模型成效，未明示技術者加上 `[技術分類推估]`]

**Agent 進度**
* ① **子公司**：[揭露具體 AI Agent 應用場景，若無則寫「無子公司層級Agent揭露」或「無具體揭露」]
* ② **集團層級 / 治理**：[例如：國泰金「Agent First」、凱基金控風管數位智庫、或成立人工智慧治理委員會等]

## 階段 3：分類映射、金控歸類與寫入 Excel
將確認屬於實際業務場景的新項目，整理為結構化 JSON 並執行 `python3 .agents/skills/tw-fin-ai-tracker/scripts/update_excel.py` 寫入 `金融業AI場景應用.xlsx`（對應欄位：`業別`、`業者`、`所屬金控`、`場景`、`類別`、`更新日期`）：

1. **業別 (`sector`)**：填入 `銀行業`、`保險業` 或 `證券期貨業`。
2. **業者 (`company`)**：填入具體金融機構或周邊單位名稱（例如：`國泰世華銀行`、`凱基證券`、`彰化銀行`）。
3. **所屬金控 (`holding`)**：
   * 依機構所屬金控填入 `金融業AI場景應用.xlsx` 表列之 14 家金控名稱（依優先順序）：
     * `元大金`（關鍵字：元大）
     * `富邦金`（關鍵字：富邦）
     * `國泰金`（關鍵字：國泰、國泰世華）
     * `中信金`（關鍵字：中信、中國信託、台灣人壽）
     * `凱基金`（關鍵字：凱基、開發）
     * `永豐金`（關鍵字：永豐）
     * `台新新光金`（關鍵字：台新、新光）
     * `玉山金`（關鍵字：玉山）
     * `兆豐金`（關鍵字：兆豐）
     * `第一金`（關鍵字：第一）
     * `華南金`（關鍵字：華南）
     * `合庫金`（關鍵字：合庫）
     * `國票金`（關鍵字：國票）
     * `臺灣金`（關鍵字：臺銀、臺灣銀行、臺灣金控）
   * 若該機構**非屬上述表列 14 家金控**（如獨立銀行、外商銀行、純網銀、獨立券商／投信、保經代或周邊機構等），請一律填入 `"未歸類"`。
4. **類別 (`category`)**：依「分類說明」工作表的 14 個類別（`RAG/KM`、`語音質檢/應用`、`生成式AI`、`比對`、`阻詐`、`M365 Copilot`、`AI Agent`、`OCR`、`智能客服`、`程式助手`、`RPA`、`模型訓練`、`App`、`其它`）進行單一分類。
5. **更新日期 (`update_date`)**：自動填入執行搜尋當天的**台灣台北時區（`Asia/Taipei`, UTC+8）日期**（格式 `YYYY-MM-DD`，腳本預設自動帶入台北時區當天日期，亦可於 JSON 中指定 `"update_date"`）。

### 執行指令範例
```bash
python3 .agents/skills/tw-fin-ai-tracker/scripts/update_excel.py '[
  {
    "sector": "證券期貨業",
    "company": "凱基證券",
    "holding": "凱基金",
    "scenario": "導入 AI 輔助投研報告摘要與智能選股問答。",
    "category": "生成式AI"
  },
  {
    "sector": "銀行業",
    "company": "彰化銀行",
    "holding": "未歸類",
    "scenario": "升級防詐監控模型，即時攔截異常轉帳。",
    "category": "阻詐"
  }
]'
```

## 階段 4：自動同步至 GitHub（選用）
更新完成後，執行 `git add 金融業AI場景應用.xlsx daily_reports/ && git commit -m "chore: update daily financial AI scenarios" && git push`，讓線上儀表板即時同步。
