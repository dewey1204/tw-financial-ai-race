### 玉山金控 / 玉山銀行
**AI 應用**
* **生成式AI**
  * ① **玉山銀行**：全面升級內部辦公生成式 AI 平台至「**GENIE 3.0**」（全行採用率逾三分之一），由單純對話問答與知識檢索（RAG）進階為多步驟推理與跨源知識整合，落實於融資評估報告生成、總經與競品市場研究及軟體工程輔助。

**Agent 進度**
* ① **子公司**：**玉山銀行**正式將 Agentic AI（代理式 AI）深入落實至「**六大核心金融應用場景**」，以「GENIE 3.0」作為全行統一 `Root Agent` 入口，透過 REST API 與模型上下文協議（MCP）動態調度專業代理人：
  * **融資評估自動化 Agent**：整合財務報表、新聞輿情與歷史信用資料，執行多步驟推理評分並自動產出綜合授信摘要報告。
  * **法遵文件稽核 Agent**：自動比對 ESG 報告與最新金融法規要求，運用多跳（Multi-hop）推理精準揪出不符條款。
  * **智慧客服 Agent**：理解顧客多管道進線意圖，精準呼叫工具（Tool Calls）執行查餘額、轉帳或申訴處理。
  * **輿情監測 Agent**：每日自動爬取上萬筆新聞、社群及公告，進行巨量資料彙整與營運影響分析。
  * **市場研究自動化 Agent**：結合網路研究（Web Research）進行多跳知識整合，自動產出競品分析與總體經濟報告。
  * **系統開發 Agent（Coding Agent）**：理解軟體開發需求，協助工程師進行程式撰寫、測試、自動 PR Review（程式碼審查）與 Bug 修復。
* ② **集團層級 / 治理**：因應 AI Agent 高頻率複雜任務與高 Token 消耗，玉山金控建構高速穩定之地端算力與混合雲架構，確保符合金融業 99.99% 系統穩定度與資安合規標準。

### 台新新光金控 / 台新銀行
**AI 應用**
* **生成式AI**
  * ① **台新銀行**：推出「**SIGMA 智慧生成式行銷助理平台**」，整合文字、圖像、影音及市場洞察生成能力，協助金融服務人員迅速傳遞市場與產品資訊，並能將即時市場快訊自動轉製為 Podcast 語音及社群多媒體內容；同時於「普惠金融 ATM & 理財訂閱制」運用生成式 AI 將專業投研轉化為淺顯圖文，榮獲第 17 屆《財訊金融獎》「金融科技創新獎－銀行類」優質獎及 2026《工商時報數位金融獎》肯定。

**Agent 進度**
* ① **子公司**：台新銀行結合「SIGMA」生成式行銷助理、法人徵信 RAG 雙引擎系統與消金「LUNA」智慧信貸決策平台，建構從前線行銷、徵審評估到客戶溝通之人機協作工作流。
* ② **集團層級 / 治理**：由金控層級「AI 治理委員會」與「台新腦 3.0」架構統籌法遵、資安與風管護欄，落實「AI 輔助、專業人員最終決策」原則。

* **傳統AI / 機器學習**
  * ① **永豐金證券**：與內政部警政署刑事警察局簽署反詐騙合作備忘錄（MOU），串聯 165 反詐情資與證券交易大數據，運用 AI 即時辨識高風險交易與港美股複委託異常態樣，主動預警高齡與一般投資人以防堵假冒投資詐騙 `[技術分類推估]`。

**Agent 進度**
* ① **子公司**：永豐投顧持續運行 Multi-Agent 架構之「永豐智投」研究員高效助手；永豐金證券全面導入 GitHub Copilot 與 M365 協作工具並招募「生成式 AI IT 培訓師」，擴大內部代理人實務落地。
* ② **集團層級 / 治理**：永豐金控以「智慧金融升級、公平待客、防堵詐騙」為核心，建立跨銀行與證券之 AI 風險預警與模型治理機制。
